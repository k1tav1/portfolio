## 🛠️ Setup

```bash
git clone https://github.com/k1tav1/portfolio.git
cd portfolio
npm install
npm run dev -- --port 3000 --hostname 0.0.0.0
# → http://localhost:3000
```

Build & Test:
```bash
npm run build
npm run test        # Playwright E2E (needs npx playwright install --with-deps)
npm run test:ui     # UI mode
```

Docker (DevOps Lab):
```bash
docker build -t derick-portfolio .
docker run -p 3000:3000 -e PORT=3000 derick-portfolio
# → http://localhost:3000
```
